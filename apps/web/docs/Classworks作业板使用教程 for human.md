## 一、软件简介

**Classworks 作业板**是一款专为班级大屏设计的作业展示与管理工具。它以卡片式布局展示当天各科作业，支持实时同步、考勤管理、随机点名、考试安排等功能，适用于教室一体机记录作业等场景。

### 主要功能

| 功能         | 说明                                                          |
| ------------ | ------------------------------------------------------------- |
| 作业展示     | 以科目卡片形式展示当天作业，支持语文、数学、英语等十类科目    |
| 实时同步     | 多设备间通过可云端实时同步作业内容，一台编辑多台可见          |
| 考勤管理     | 记录学生到课、请假、迟到、不参与状态，支持批量操作            |
| 随机点名     | 课堂随机抽取学生，支持姓名模式和学号模式，可排除请假/迟到学生 |
| 考试安排     | 管理考试日程，在作业板上显示考试卡片，考前自动提醒            |
| 设备聊天     | 同班级多设备间实时聊天，支持发送通知                          |
| UAF 导入导出 | 支持将作业导出为标准 UAF 格式 PDF，或从 UAF PDF 批量导入作业  |

### 运行环境

- **浏览器**：推荐 Chrome、Edge 等现代浏览器（不建议使用 360、夸克、QQ 等兼容性较差的浏览器）
- **设备**：教室一体机、电脑、平板、手机均可使用

## 二、快速开始

### 2.1 首次打开

在浏览器中输入 Classworks 作业板的网址，首次打开时会看到初始化界面。

### 2.2 选择数据存储方式

系统提供多种数据存储模式，在首次使用时需要选择：

- **本地模式（local）**：数据仅保存在当前设备的浏览器中，不与其他设备同步。适合单设备使用。
- **云端模式（kv-server / classworkscloud）**：数据保存在云端服务器，多设备间实时同步。需要配置服务器地址和访问令牌（Token）。
- **双模式（dual-cloud / dual-server）**：同时使用本地和云端，离线时使用本地数据，联网后自动合并同步。

> **提示**：如果您是班级大屏管理员，建议使用云端模式或双模式，这样可以在办公室电脑上编辑作业，教室大屏自动显示。

### 2.3 设置班级编号

首次使用时，系统会提示设置班级编号（如"高三一班"）。班级编号会显示在页面顶部，用于识别当前设备所属的班级。

- 输入班级名称后点击「确认」
- 也可以点击「取消」稍后设置（后续可在设置中修改）

### 2.4 设置学生/教师身份（云端模式）

如果使用云端模式且令牌（Token）类型为学生或教师，系统会提示设置姓名：

- **学生令牌**：从学生列表中选择自己的姓名
- **教师令牌**：输入教师姓名，可选择是否为班主任，并填写任教科目

设置完成后，姓名会显示在页面顶部，用于设备聊天和操作记录。

## 三、首页界面详解

首页（作业板）是最常用的界面，整体布局大致如下：

```
┌─────────────────────────────────────────────────────────┐
│  顶部导航栏：班级名称 | 日期 | 令牌信息 | 聊天 | 消息 | 设置 │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐               │
│  │  语文作业  │ │  数学作业  │ │  英语作业  │   作业卡片区  │
│  │  ......   │ │  ......   │ │  ......   │               │
│  └──────────┘ └──────────┘ └──────────┘               │
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐               │
│  │ 考试安排  │ │  时间卡片  │ │  一言卡片  │   功能卡片区  │
│  └──────────┘ └──────────┘ └──────────┘               │
│                                                         │
│  [上传/同步] [全屏] [随机点名] [考试看板] [列表] [传输]  │  操作按钮区
│                                                         │
├─────────────────────────────────────────────────────────┤
│  [昨天] [日期] [明天] | [缩小] [放大] | [刷新]          │  浮动工具栏
└─────────────────────────────────────────────────────────┘
```

### 3.1 顶部导航栏

顶部导航栏显示以下信息：

- **班级名称与日期**：左侧显示"班级名称 - 今天的作业"（查看历史日期时会显示对应日期）
- **令牌信息**：云端模式下显示当前令牌类型和名称，点击可修改
- **聊天按钮**：打开设备聊天室（右下角浮窗）
- **消息按钮**：查看系统消息记录，有未读消息时显示红点
- **设置按钮**：进入设置页面

### 3.2 作业卡片区

作业卡片按科目分类展示，默认包含以下科目：

> 语文、数学、英语、物理、化学、生物、政治、历史、地理、其他

- 有作业内容的科目会显示卡片，无作业的科目默认隐藏（可在设置中改为显示空科目）
- 点击科目卡片即可编辑该科目的作业内容
- 卡片内容支持多行文本，自动换行显示
- 卡片顺序按科目预设顺序排列，可在设置中自定义科目顺序

### 3.3 功能卡片区

除了作业卡片，首页还可以显示以下功能卡片：

- **考试安排卡片**：显示近期考试信息，点击可查看/编辑考试详情
- **时间卡片**：显示当前日期和时间（可在设置中开启/关闭）
- **一言卡片**：显示每日一句励志名言（可在设置中开启/关闭）
- **自定义卡片**：可添加任意标题和内容的卡片，用于展示通知、提醒等

### 3.4 考勤侧边栏

桌面端右侧显示考勤统计侧边栏：

- 显示班级总人数、到课人数、请假人数、迟到人数
- 点击侧边栏可打开考勤管理对话框进行详细设置

> 移动端考勤信息会以卡片形式显示在作业区域顶部。

### 3.5 操作按钮区

作业卡片下方是一排操作按钮：

| 按钮                | 功能                                                                     |
| ------------------- | ------------------------------------------------------------------------ |
| **上传 / 同步完成** | 手动上传数据到云端（未同步时显示红色"上传"，已同步时显示绿色"同步完成"） |
| **全屏 / 退出全屏** | 切换浏览器全屏模式，适合教室大屏展示                                     |
| **随机点名**        | 打开随机点名工具                                                         |
| **考试看板**        | 跳转到考试安排管理页面                                                   |
| **列表**            | 跳转到列表管理页面                                                       |
| **传输**            | 展开 UAF 导入/导出菜单                                                   |
| **发送通知**        | 发送紧急通知到同班级所有设备（需开发者模式）                             |

### 3.6 浮动工具栏

页面底部中央有一个半透明的浮动工具栏：

| 按钮     | 功能                           |
| -------- | ------------------------------ |
| **昨天** | 切换到前一天的作业             |
| **日期** | 打开日历选择器，跳转到任意日期 |
| **明天** | 切换到后一天的作业             |
| **缩小** | 减小作业卡片字体大小           |
| **放大** | 增大作业卡片字体大小           |
| **刷新** | 从云端重新加载当前日期的数据   |

> 当查看历史日期且该日期有作业时，右下角会出现「复制到今天」按钮，可一键将历史作业复制到当天。

## 四、作业管理

### 4.1 添加/编辑作业

1. 在首页点击对应科目的作业卡片
2. 弹出编辑对话框，在文本框中输入作业内容
3. 支持多行输入，每行一条作业项
4. 编辑完成后：
   - **自动保存模式**：关闭对话框自动保存（可在设置中开启）
   - **手动保存模式**：点击「保存」按钮保存

> **提示**：作业内容支持纯文本，可使用换行、空格、数字编号等方式排版。

### 4.2 添加自定义卡片

如果需要展示非标准科目的内容（如通知、提醒、班级公告等），可以添加自定义卡片：

1. 在操作按钮区点击「测试卡片」（需在设置中开启开发者模式）
2. 或通过 UAF 导入功能批量创建
3. 自定义卡片会显示在作业区域末尾，点击可编辑标题和内容
4. 将自定义卡片内容清空并保存，即可删除该卡片

### 4.3 查看历史作业

通过浮动工具栏可以查看任意日期的历史作业：

- 点击「昨天」/「明天」逐日切换
- 点击「日期」打开日历，选择任意日期

### 4.4 复制历史作业到今天

当查看历史日期的作业时，如果想把那天的作业复用到今天：

1. 确认当前查看的是你想复用的日期（非今天）
2. 点击右下角的「复制到今天」按钮
3. 系统会将该日期的所有作业内容复制到今天，替换今天原有的作业
4. 复制完成后自动跳转到今天的页面

> **注意**：此操作会替换今天已有的作业内容，请确认后再操作。

### 4.5 删除作业

将某科目的作业内容全部清空，保存后该科目卡片会自动隐藏。

## 五、考勤管理

### 5.1 打开考勤管理

- **桌面端**：点击右侧考勤侧边栏
- **移动端**：点击作业区域顶部的考勤卡片
- 两种方式都会打开考勤管理对话框

### 5.2 设置学生考勤状态

考勤管理对话框中，每位学生对应一行，包含四个状态按钮：

| 状态       | 图标 | 颜色 | 说明                |
| ---------- | ---- | ---- | ------------------- |
| **到课**   | ✓    | 绿色 | 正常到校上课        |
| **请假**   | ✗    | 红色 | 因病/事请假         |
| **迟到**   | ⏰   | 黄色 | 迟到                |
| **不参与** | ⊘    | 灰色 | 不参与本次点名/活动 |

操作方式：

- 点击对应状态按钮即可设置该学生的考勤状态
- 再次点击「到课」可取消其他状态，恢复为正常到课
- 每位学生同一时间只能有一种非常态状态

### 5.3 搜索与筛选

- **搜索框**：输入学生姓名或姓氏进行筛选，支持模糊搜索
- **姓氏快捷筛选**：搜索框下方会自动列出班级中所有姓氏及对应人数，点击姓氏可快速筛选该姓学生
- **状态筛选**：点击「到课」「请假」「迟到」「不参与」标签，可只显示对应状态的学生（可多选）

### 5.4 批量操作

对话框底部提供批量操作按钮，可一键设置所有学生的状态：

- **全部到齐**：将所有学生设为到课
- **全部请假**：将所有学生设为请假
- **全部迟到**：将所有学生设为迟到
- **全部不参与**：将所有学生设为不参与

### 5.5 保存考勤

- 点击对话框右下角的「保存」按钮保存考勤设置
- 如果开启了自动保存，关闭对话框时会自动保存
- 考勤数据与作业数据按日期分别保存，每天的考勤记录独立

## 六、随机点名

### 6.1 打开随机点名

点击操作按钮区的「随机点名」按钮，打开随机点名对话框。

### 6.2 选择抽取人数

- 使用「+」「-」按钮调整抽取人数（1~10人，且不超过可抽取学生数）
- 人数会显示在中央大号数字中

### 6.3 选择抽取模式

随机点名支持两种模式：

#### 姓名模式

从班级学生名单中随机抽取姓名。可设置过滤条件：

- **包含/排除迟到学生**：是否将迟到学生纳入抽取范围
- **包含/排除请假学生**：是否将请假学生纳入抽取范围
- **包含/排除不参与学生**：是否将不参与学生纳入抽取范围

> 过滤条件会根据当天考勤设置自动生效，也可以在点名对话框中临时调整。

#### 学号模式

按学号范围随机抽取，不依赖学生名单：

- 设置学号最小值和最大值（1~100）
- 系统会在该范围内随机抽取学号，显示为"01号""02号"等格式

### 6.4 开始抽取

1. 设置好人数、模式和过滤条件后
2. 点击「开始抽取」按钮
3. 系统会播放滚动动画，姓名/学号快速切换后逐渐减速
4. 最终高亮显示被抽中的学生

### 6.5 抽取结果操作

抽取完成后：

- 结果以卡片形式展示，每位被抽中学生一张卡片
- 每张卡片右侧有一个「重新抽取」按钮，可单独替换该位置的学生（从剩余未被抽中的学生中随机选择）
- 点击「重新抽取」按钮可全部重新抽取
- 点击「关闭」按钮退出随机点名

## 七、考试安排

### 7.1 考试看板

点击操作按钮区的「考试看板」按钮，进入考试安排管理页面。

考试看板以时间轴或日历形式展示所有已安排的考试，包括：

- 考试名称
- 考试日期和时间
- 考试科目
- 考试地点（如有）
- 考试状态（未开始/进行中/已结束）

### 7.2 添加考试到作业板

在首页操作按钮区，点击「考试看板」旁边的「+」按钮，打开添加考试对话框：

1. 从已有考试列表中选择要添加到作业板的考试
2. 已添加的考试会显示勾选标记
3. 选择完成后考试卡片会显示在首页作业区域

> 如果近期（两天内）有考试安排但作业板上没有显示考试卡片，系统会自动弹出提示，可点击「一键添加」快速添加所有近期考试。

### 7.3 查看/编辑考试详情

- 点击首页的考试卡片，打开考试详情对话框
- 可以查看考试的详细信息
- 可以编辑考试名称、时间、科目等信息
- 可以从作业板移除该考试卡片（不删除考试本身）

### 7.4 考试编辑器

在考试看板中点击具体考试，可以进入考试编辑器，详细设置：

- 考试基本信息（名称、时间、地点）
- 考试科目安排（各科目考试时间段）
- 考试注意事项
- 监考教师安排

## 八、设备聊天室与通知

### 8.1 打开设备聊天室

- 点击顶部导航栏的聊天按钮，或
- 点击右下角的聊天浮窗按钮

聊天室以浮窗形式显示在右下角，不会遮挡作业内容。

### 8.2 聊天功能

- **发送消息**：在底部输入框输入文字，点击「发送」或按回车键发送
- **表情**：点击表情按钮可插入常用表情
- **消息显示**：自己发送的消息显示在右侧，其他设备的消息显示在左侧，附带发送设备名称
- **未读提示**：聊天室关闭时，有新消息会在聊天按钮上显示红色未读数

> 所有使用同一班级令牌（Token）的设备都在同一个聊天室中，适合教师之间或师生之间沟通。

### 8.3 事件日志

聊天室支持切换到「事件」模式，查看所有设备事件记录：

- **聊天事件**：所有聊天消息记录
- **KV 变化事件**：作业数据被修改的记录（谁在什么时间修改了什么）
- **其他事件**：紧急通知、设备上下线等

事件统计会显示在顶部，事件列表支持分页浏览。

### 8.4 紧急通知

管理员可以向同班级所有设备发送紧急通知：

1. 在操作按钮区点击「发送通知」（需在设置中开启对应选项）
2. 输入通知标题和内容
3. 点击发送
4. 所有在线设备会立即弹出通知弹窗，同时在事件日志中记录

> 紧急通知会以醒目的方式显示在所有设备屏幕上，适合发布重要通知（如临时调课、紧急集合等）。

## 九、UAF 作业单导入导出

UAF（Unified Assignment Format）是一种标准化的作业单格式，以 PDF 文件存储，内嵌作业数据。

### 9.1 导出 UAF

1. 点击操作按钮区的「传输」按钮，选择「导出 UAF」
2. 在导出对话框中：
   - **选择导出日期**：默认是当前日期，可修改为任意日期
   - **选择作业项**：系统会列出该日期的所有作业，勾选要导出的科目
   - 有问题的作业项（如格式不规范）会标红且无法勾选
   - 可点击「选择全部有效作业」一键勾选所有有效项
3. **预览导出效果**：右侧实时预览导出的 PDF 样式
4. **调整字体设置**：展开「导出字体设置」，可分别调整标题、正文、标签的字号和字重
5. 点击「导出所选作业」，PDF 文件会自动下载到本地

导出的 PDF 文件名格式为：`UAF-日期.pdf`

### 9.2 导入 UAF

1. 点击操作按钮区的「传输」按钮，选择「导入 UAF」
2. 选择一个 UAF 格式的 PDF 文件
3. 系统会解析 PDF 中的作业数据，显示导入计划：
   - 按日期分组显示所有作业项
   - 每项作业显示科目、内容预览
   - 如果目标日期已有同名科目作业，会标记「已有同名卡片」冲突
4. **处理冲突**：对于冲突项，可以选择：
   - **保留现有**：不导入该项，保留当前已有内容
   - **覆盖现有**：用导入的内容替换当前内容
   - 对于无冲突项，可以选择「导入」或「跳过」
5. 点击「确认导入」执行导入
6. 导入完成后，如果当前日期在导入范围内，页面会自动刷新显示新导入的作业

> **注意**：仅支持内嵌 `uaf_payload.csv` 数据的标准 UAF PDF 文件，普通 PDF 无法导入。

## 十、数据同步与离线使用

### 10.1 同步机制

Classworks 支持多种数据存储模式，同步行为各不相同：

| 模式            | 本地存储 | 云端存储 | 实时同步 | 离线可用 |
| --------------- | -------- | -------- | -------- | -------- |
| local           | ✓        | ✗        | ✗        | ✓        |
| kv-server       | ✗        | ✓        | ✓        | ✗        |
| classworkscloud | ✗        | ✓        | ✓        | ✗        |
| dual-cloud      | ✓        | ✓        | ✓        | ✓        |
| dual-server     | ✓        | ✓        | ✓        | ✓        |

- **实时同步**：一台设备修改作业后，其他设备会在几秒内自动更新
- **自动刷新**：系统会按设定间隔自动从云端刷新数据（可在设置中调整间隔）
- **手动刷新**：点击浮动工具栏的「刷新」按钮可立即同步

### 10.2 同步状态指示

- 操作按钮区的第一个按钮显示同步状态：
  - **绿色「同步完成」**：本地数据与云端一致
  - **红色「上传」**：本地有未同步的修改，点击可手动上传
- 数据加载中时，编辑功能会暂时禁用，防止冲突

### 10.3 离线使用

在双模式（dual-cloud / dual-server）下：

- 网络断开时，系统自动切换到本地数据，所有功能正常使用
- 离线期间的修改会保存在本地队列中
- 网络恢复后，系统自动将离线修改同步到云端
- 如果离线期间其他设备也修改了同一日期的作业，系统会按合并策略处理冲突

> **建议**：教室大屏使用双模式，确保网络故障时作业板仍能正常显示。

### 10.4 命名空间切换

如果设备的命名空间（班级标识）发生变化，系统会弹出提示：

- **导出备份并清空**：先导出本地数据备份，然后清空本地数据，加载新班级的云端数据（推荐）
- **保留数据并切换**：保留本地数据，与新班级数据合并使用（可能导致数据混淆）
- **暂不处理**：关闭提示，下次启动会再次提示

> 命名空间切换通常发生在更换班级令牌时。

## 十一、设置详解

点击顶部导航栏的「设置」按钮进入设置页面。设置页面左侧为分类导航，右侧为对应设置项。

### 11.1 首页

- **关于 Classworks**：软件版本信息、开源声明
- **Classworks KV 入口**：快速跳转到 KV 数据库管理后台
- **注意事项**：
  - 不要使用浏览器清除缓存功能，否则会导致配置丢失
  - 推荐使用 Chrome 或 Edge 浏览器

### 11.2 数据与同步

#### 服务器设置

- **服务器地址**：云端 KV 服务器的 URL
- **访问令牌（Token）**：用于身份验证的密钥，从 KV 管理后台获取
- **班级编号**：当前设备所属班级名称
- **班级编号来源**：使用本地设置的班级编号，还是从云端命名空间获取

#### 数据提供者

- **存储模式**：选择 local / kv-server / classworkscloud / dual-cloud / dual-server
- 不同模式的区别见[第十章](#十数据同步与离线使用)

#### KV 数据库

- 查看当前 KV 服务器连接状态
- 测试连接
- 查看存储空间使用情况

#### 同步设置

- **自动同步**：开启/关闭自动同步
- **最小同步间隔**：两次同步之间的最短时间间隔
- **最大同步间隔**：两次同步之间的最长时间间隔
- **自动刷新**：开启/关闭定时自动从云端刷新数据
- **刷新间隔**：自动刷新的时间间隔（秒）

#### 设置链接生成器

- 可将当前配置（服务器地址、班级编号等）编码为一个 URL
- 分享该 URL 给其他设备，打开后可一键应用相同配置
- 适合快速配置多台教室设备

### 11.3 科目与作业

#### 科目管理

- **添加科目**：添加自定义科目
- **删除科目**：删除不需要的科目（默认十科不可删除）
- **调整顺序**：拖拽或使用上下箭头调整科目显示顺序
- 科目顺序决定作业卡片在首页的排列顺序

#### 作业模板

- 为每个科目设置默认作业模板
- 新建该科目作业时，自动填入模板内容
- 适合有固定作业格式的科目（如"1. 练习册第X页 2. 背诵..."）

### 11.4 人员与考勤

#### 学生列表

- **添加学生**：逐个添加或批量导入学生姓名
- **编辑学生**：修改学生姓名
- **删除学生**：移除学生
- **调整顺序**：调整学生在列表中的顺序（影响考勤和点名的显示顺序）
- **批量导入**：支持从文本批量导入，每行一个姓名

#### 教师列表

- **添加教师**：添加教师姓名，可设置是否为班主任、任教科目
- **编辑教师**：修改教师信息
- **删除教师**：移除教师

#### 自动考勤

- 配置自动考勤规则，如：
  - 特定日期自动标记某些学生为请假
  - 根据课表自动设置参与/不参与
- 减少手动考勤的重复操作

### 11.5 显示与外观

#### 主题设置

- **浅色/深色模式**：切换界面主题
- **主题色**：选择界面强调色
- **跟随系统**：是否跟随操作系统的深浅色设置

#### 显示设置

- **字体大小**：作业卡片的基础字体大小（也可通过浮动工具栏的放大/缩小调整）
- **空科目显示**：是否显示没有作业的科目卡片
- **动态排序**：是否根据内容量自动调整卡片布局
- **全屏按钮**：是否在操作区显示全屏按钮
- **考试看板按钮**：是否显示考试看板入口
- **列表按钮**：是否显示列表入口
- **UAF 传输按钮**：是否显示 UAF 导入导出按钮
- **随机点名按钮**：是否显示随机点名按钮
- **强制桌面模式**：在移动端也使用桌面端布局（适合大屏平板）

#### 背景设置

- **背景图片**：设置页面背景图片
- **背景透明度**：调整背景图片的透明度
- **背景模糊**：调整背景模糊程度

#### 通知声音

- **消息提示音**：收到聊天消息时是否播放提示音
- **紧急通知提示音**：收到紧急通知时是否播放提示音
- **音量调节**：提示音音量

#### 一言设置

- **启用一言**：是否在首页显示一言卡片
- **一言来源**：选择一言的数据源（如本地词库、第三方 API）
- **更新频率**：一言的更换频率（每天/每次刷新）

### 11.6 编辑与行为

#### 作业编辑设置

- **自动保存**：编辑作业后关闭对话框时自动保存（无需点保存按钮）
- **禁止非今天自动保存**：查看历史日期时，不自动保存修改（防止误改历史数据）
- **非今天保存确认**：修改历史日期作业时，保存前弹出确认对话框
- **编辑前刷新**：打开编辑对话框前先从云端刷新数据，确保编辑的是最新版本
- **禁止编辑过往数据**：完全禁止修改今天之前的作业数据

#### 刷新设置

- **编辑前刷新**：同编辑设置中的对应选项
- **自动刷新间隔**：同数据同步中的对应选项

#### 随机点名设置

- **默认抽取人数**：打开随机点名时的默认人数
- **默认模式**：姓名模式 / 学号模式
- **默认排除请假**：是否默认排除请假学生
- **默认排除迟到**：是否默认排除迟到学生
- **默认排除不参与**：是否默认排除不参与学生
- **学号最小值**：学号模式的默认最小值
- **学号最大值**：学号模式的默认最大值
- **抽取动画**：是否播放滚动动画（关闭后直接显示结果）

### 11.7 开发者

> 普通用户无需使用此分类，以下功能仅供高级用户和开发者调试。

- **开发者模式**：开启后显示测试卡片、发送通知等高级功能
- **所有设置**：浏览和修改所有底层设置项（包括未在界面中暴露的设置）
- 可查看设置的技术键名、复制设置值、导出全部配置

## 十二、实用技巧与快捷键

### 12.1 高效操作技巧

1. **快速配置多台设备**：在一台设备上配置好服务器和 Token 后，使用「设置链接生成器」生成配置链接，其他设备打开链接即可一键完成配置。

2. **批量导入学生**：在学生列表管理中，将所有学生姓名复制到文本框（每行一个），可一次性导入全班学生。

3. **复用历史作业**：如果某天的作业与之前某天一致，先切换到历史日期，点击「复制到今天」，比重新输入快很多。

4. **课前快速检查考勤**：打开考勤管理，先点「全部到齐」，再逐个将请假/迟到的学生设为对应状态，比逐个设置更高效。

5. **大屏展示优化**：
   - 开启全屏模式
   - 适当调大字体（浮动工具栏的放大按钮）
   - 放学后建议关闭显示器以节约能源

### 12.2 PWA 安装

Classworks 支持 PWA（渐进式 Web 应用），可以像原生应用一样安装到电脑或手机：

- **Chrome / Edge**：地址栏右侧会出现安装图标，点击即可安装
- 安装后会在桌面/开始菜单创建快捷方式
- 打开后无浏览器地址栏，更像原生应用
- 支持离线启动

> 首次打开时如果检测到支持 PWA，页面会显示安装提示卡片。

### 12.3 数据备份

定期备份数据可以防止意外丢失：

1. **命名空间切换时自动备份**：更换班级时，系统会提示导出本地数据备份
2. **手动备份**：在缓存管理页面（`/CacheManagement`）可以导出所有本地数据为 JSON 文件
3. **UAF 导出**：定期将作业导出为 UAF PDF 存档

## 十三、常见问题与故障排除

### 13.1 页面加载问题

**Q：页面空白或加载失败？**

- 检查网络连接是否正常
- 尝试刷新页面（按 F5 或 Ctrl+R）
- 清除浏览器缓存后重试（注意：清除缓存会丢失本地配置，建议先备份）
- 确认使用的是 Chrome 或 Edge 浏览器，不建议使用 360、夸克、QQ 等浏览器

**Q：页面显示"加载失败，请检查网络连接后刷新页面"？**

- 这是页面资源加载失败的提示，通常是网络问题
- 点击页面上的「刷新页面」按钮，或按 F5 刷新
- 如果多次刷新仍失败，检查网络连接

### 13.2 数据同步问题

**Q：修改作业后其他设备没有更新？**

- 确认所有设备使用相同的服务器地址和 Token
- 点击操作按钮区的「上传」按钮手动同步
- 点击浮动工具栏的「刷新」按钮在其他设备上手动拉取
- 检查网络连接是否正常
- 确认同步设置中开启了自动同步

**Q：显示"上传"按钮但点击后没有反应？**

- 可能正在加载中，稍等片刻再试
- 检查服务器地址是否正确
- 查看浏览器控制台（F12）是否有报错信息

**Q：离线修改的数据没有同步到云端？**

- 确认使用的是双模式（dual-cloud / dual-server），纯云端模式不支持离线
- 网络恢复后等待片刻，系统会自动同步
- 如果长时间未同步，点击「上传」按钮手动触发
- 检查离线队列中是否有失败的同步任务

### 13.3 编辑问题

**Q：点击作业卡片没有反应，无法编辑？**

- 可能正在加载数据，等待加载完成后再试
- 如果使用的是只读令牌（学生令牌），则没有编辑权限
- 如果查看的是历史日期且开启了"禁止编辑过往数据"，则无法编辑
- 检查是否有其他对话框正在打开

**Q：编辑的内容没有保存？**

- 确认是否开启了自动保存（设置 → 编辑与行为 → 自动保存）
- 如果未开启自动保存，需要手动点击「保存」按钮
- 如果编辑的是历史日期，确认是否开启了"禁止非今天自动保存"
- 检查网络连接，云端模式下保存需要网络

### 13.4 考勤问题

**Q：学生列表为空？**

- 需要先在设置 → 人员与考勤 → 学生列表中添加学生
- 如果使用云端模式，确认学生列表已同步到云端
- 尝试刷新页面重新加载

**Q：考勤数据丢失？**

- 考勤数据按日期保存，切换日期后会加载对应日期的考勤
- 确认是否在正确的日期下查看考勤
- 检查是否误操作清空了考勤数据

### 13.5 随机点名问题

**Q：随机点名显示"没有可抽取的学生"？**

- 姓名模式下：确认学生列表不为空，且过滤条件没有排除所有学生
- 学号模式下：确认学号范围设置正确（最小值 ≤ 最大值）
- 尝试调整过滤条件或学号范围

**Q：抽取结果不随机/有规律？**

- Classworks 的随机点名使用真随机算法，结果预先确定后通过动画展示，不存在"作弊"
- 如果对某次结果有疑问，可以点击「重新抽取」重新随机

### 13.6 UAF 导入导出问题

**Q：导出的 PDF 打不开或格式错乱？**

- 确认使用支持 PDF 查看器的应用打开
- 尝试调整导出字体设置后重新导出
- 如果内容过长，可能导致分页异常，尝试减少导出项

**Q：导入 UAF 时提示"无法解析"？**

- 确认选择的是标准 UAF 格式 PDF（内嵌 `uaf_payload.csv` 数据）
- 普通 PDF 文件无法导入，需要使用 Classworks 导出的 UAF PDF
- 确认文件没有损坏

### 13.7 其他问题

**Q：更换 Token 后数据混乱？**

- 更换 Token 意味着切换班级/命名空间，系统会弹出命名空间切换提示
- 建议选择「导出备份并清空」，先备份旧班级数据，再加载新班级数据
- 如果选择了「保留数据并切换」，新旧数据可能混合，建议在缓存管理中清理旧数据

**Q：页面字体太小/太大？**

- 使用浮动工具栏的「缩小」「放大」按钮调整
- 或在设置 → 显示与外观 → 显示设置中调整字体大小
- 字体大小范围为 16px ~ 100px

**Q：如何完全重置应用？**

- 清除浏览器的站点数据（Cookie、本地存储、IndexedDB）
- 注意：这会删除所有本地配置和数据，请先备份
- 刷新页面后重新开始配置

**Q：忘记了服务器地址或 Token？**

- 联系班级管理员或 KV 服务器管理员获取
- Token 可以在 KV 管理后台重新生成
- 如果有其他已配置的设备，可以使用「设置链接生成器」生成配置链接获取
